# Результаты проверки — 2026-10-23

Среда: Java Temurin 17.0.17, Gradle 8.8, Minecraft 1.20.1, Forge 47.4.4,
KubeJS 2001.6.5-build.16, Rhino 2001.2.3-build.10, Architectury 9.2.14.

Команда (localMods указывает на каталог с тремя зависимостями):

```bash
./gradlew -PlocalMods=/path/to/mods build runGameTestServer -x downloadAssets --offline
```

Итог:

```text

[+++++++++++]
========= 11 GAME TESTS COMPLETE ======================
All 11 required tests passed :)
BUILD SUCCESSFUL in 1m 19s
```

Проверены:

1. Формула HP для трёх игроков и отсутствие повторного масштабирования.
2. HP для 0–4 игроков, коэффициент 0.5, отклонение NaN и отрицательного коэффициента.
3. Граница 40 включительно, 40.01 снаружи, углы куба снаружи, исключение spectator.
4. Сохранение/чтение NBT моба: атрибут HP и UUID получателей.
5. Копии дропа без игрока-убийцы: независимые ItemStack с одинаковым NBT/именем и разными владельцами.
6. Фильтрация broadcastToPlayer, запрет чужого подбора, разрешение подбора владельцем, NBT предмета после восстановления сущности.
7. Запрет воронки для персональных предметов и обычная работа для общего дропа.
8. Исключения общего лута и обычный дроп при нуле игроков.
9. Регистрация настоящим JS-скриптом KubeJS, обработка реального EntityJoinLevelEvent, игнорирование загрузки с диска.
10. Запрет обоих направлений слияния личного и общего предмета.
11. Реальный спавн с тремя серверными FakePlayer: два внутри сферы, один в углу куба вне сферы; HP=40, сохранены два UUID, уход игрока не меняет HP.

Тесты выполнялись в Forge GameTest сервере с реальными Minecraft-классами и применёнными Mixin. Игроки в автоматических тестах — серверные FakePlayer, а не подключённые клиенты. Проверка HP/UUID после сохранения создаёт новые сущности из NBT; отдельный полный перезапуск сервера с двумя клиентами не выполнялся.

Готовый JAR прошёл reobfJar. Refmap содержит SRG-цели всех четырёх инъекций и включён в JAR; MixinConfigs прописан в манифесте. Запуск полного пользовательского модпака и взаимодействия со всеми его модами не проверялись. Сетевые сообщения Yggdrasil/version checker в изолированной среде не влияли на результат GameTest.
